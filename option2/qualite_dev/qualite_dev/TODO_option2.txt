 AIDE-MEMOIRE DES ERREURS FREQUENTES
------------------------------------------------------------------------
- "Connection refused" sur le port 2222
  -> conteneur git-server non demarre (un "build" ne demarre rien).
     Faire "docker compose up -d".

- "Permission denied (publickey)"
  -> authorized_keys ne contient pas la bonne cle publique, ou image
     git non rebuild. (Deja resolu chez toi.)

- "fatal: cannot exec 'hooks/post-receive': No such file or directory"
  -> fins de ligne CRLF dans post-receive.sh (shebang #!/bin/bash\r).
     sed -i 's/\r$//' git-serv/post-receive.sh
     puis docker cp vers le conteneur (ou rebuild + recreate du volume).

- ssh ou git push demande un MOT DE PASSE
  -> la cle ~/.ssh/qualite_git n'est pas utilisee. Utiliser :
       ssh  : ssh -i ~/.ssh/qualite_git -p 2222 git_user@localhost
       git  : GIT_SSH_COMMAND="ssh -i ~/.ssh/qualite_git" git push ...
     ou, mieux, l'alias "git-local" de ~/.ssh/config (etape 4).
     git_user n'a pas de mot de passe : l'invite ne peut jamais aboutir.

- Hook silencieux / pipeline non lance
  -> curl absent (OK maintenant), job mal nomme, token faux, ou
     git-server ne joint pas jenkins.

- HTTP 403 sur /job/.../build?token=...
  -> X-Required-Permission: hudson.model.Hudson.Read : decocher
     "Prevent anonymous read access" (etape 6).
  -> POST bloque par CSRF : utiliser GET (pas de -X POST).

- "No item named tri-bulles-preprod found"
  -> ancien Jenkinsfile.dev ; remplacer par tri-bulles-prod,
     commit puis push.

- "Host key verification failed" dans Jenkins
  -> Git Host Key Verification mal configure (etape 6).

- Jenkins ne clone pas le depot
  -> URL localhost:2222 au lieu de git-server ; credential absent ;
     branche differente de main.

- Prod installe mais binaire perdu apres "docker compose down"
  -> volume prod_install absent (il est declare maintenant).

- Compose refuse de demarrer : port 8080 deja pris
  -> un ancien conteneur Jenkins tourne encore.

- "service jenkins refers to undefined volume ..."
  -> volume utilise dans un service mais non declare dans la section
     "volumes:" du bas du compose.
